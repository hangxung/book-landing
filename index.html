01 — Tổng quan

Cuốn sách dành cho ai?

Bạn là sinh viên mới vào ngành, người muốn chuyển nghề, hay đơn giản là tò mò một trang web được làm ra như thế nào? Cuốn sách được viết cho đúng những người đó: giải thích bằng ngôn ngữ đời thường, ví dụ nhỏ, và mỗi chương kết thúc bằng một sản phẩm bạn có thể mở ra xem ngay.

  • Không cần kiến thức lập trình trước
  • Học qua 5 dự án thực tế, từ dễ đến khó
  • Mã nguồn mẫu cho từng chương trên GitHub
  • Cập nhật theo Bootstrap 5.3 mới nhất

  1. Trình duyệt đọc một trang web như thế nào

  3. Văn bản, hình ảnh, liên kết và bảng
  4. Form và HTML ngữ nghĩa

  1. Selector, màu sắc và font chữ
  2. Box model — bí mật của mọi bố cục
  3. Flexbox và CSS Grid
  4. Media query và thiết kế responsive

  1. Hệ thống lưới 12 cột
  2. Component: navbar, card, modal, carousel
  3. Tùy biến giao diện Bootstrap
  4. Dự án cuối: landing page và đưa lên GitHub Pages
